# JavaScript Learning

A collection of JavaScript projects documenting my progression from foundational JavaScript and Node.js exercises toward more advanced application development.

<br>

## About This Repository

I am a software development engineer in test (SDET) with 20 years of professional experience in software development and test automation. I created this repository to build practical experience with the JavaScript ecosystem, with a particular focus on developing the skills needed to transition into TypeScript and modern browser automation with Playwright.

Rather than being a collection of isolated tutorials, this repository is intended to document my progression as I take on increasingly complex problems and apply what I learn to working code.

The projects here are deliberately preserved as part of that progression. They provide a prospective employer with an opportunity to see not only what I can build, but how my JavaScript skills develop as the problems become more challenging.

<br>

## Why This Repository Exists

My professional experience gives me a strong foundation in software engineering, testing, automation, debugging, and problem solving. This repository represents my deliberate expansion of that foundation into the JavaScript ecosystem and, ultimately, broader software development.

As the repository grows, the expectation is that the projects will become progressively more complex and demonstrate:

- Stronger JavaScript fundamentals
- TypeScript proficiency
- More sophisticated application design
- Increased use of automated testing
- Modern tooling and development practices
- Browser automation with Playwright
- Eventually, potentially, full-stack application development

This repository is therefore less about any individual exercise and more about demonstrating the continuous development of practical engineering skills through increasingly complex problems.
